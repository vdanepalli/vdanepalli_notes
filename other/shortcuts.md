### Mac Shortcuts

Here are some commonly used Mac shortcuts formatted in markdown:

#### **General Shortcuts**
- `⌘ + C`: Copy
- `⌘ + X`: Cut
- `⌘ + V`: Paste
- `⇧ + ⌘ + V`: Move
- `⌘ + Z`: Undo
- `⇧ + ⌘ + Z`: Redo
- `⌘ + A`: Select All
- `⌘ + Q`: Quit App
- `⌘ + W`: Close Window
- `⌘ + N`: New Window
- `⌘ + T`: New Tab
- `⌘ + ,`: Open Preferences for the active app

#### **Finder Shortcuts**
- `⌘ + N`: New Finder Window
- `⌘ + D`: Duplicate selected item
- `⌘ + I`: Get Info
- `⌘ + ⇧ + G`: Go to Folder
- `⌘ + ⇧ + N`: New Folder
- `⌘ + Delete`: Move to Trash
- `⌘ + ⇧ + Delete`: Empty Trash
- `⌘ + ⇧ + period`: Toggle hidden files

#### **Window Management**
- `⌘ + M`: Minimize Window
- `⌘ + H`: Hide active app
- `⌘ + ⇧ + H`: Hide other apps
- `⌘ + Tab`: Switch between open apps
- `⌘ + `: Switch between windows of the same app

#### **Text Editing**
- `⌘ + ↑`: Move cursor to beginning of document
- `⌘ + ↓`: Move cursor to end of document
- `⌘ + ←`: Move cursor to beginning of line
- `⌘ + →`: Move cursor to end of line
- `Option + ←`: Move cursor to beginning of previous word
- `Option + →`: Move cursor to end of next word
- `⌘ + ⇧ + ←/→/↑/↓`: Select text from cursor to beginning/end of line/document
- `Option + Delete`: Delete word to the left of the cursor
- `⌘ + Delete`: Delete line to the left of the cursor

#### **Screenshots**
- `⌘ + ⇧ + 3`: Capture entire screen
- `⌘ + ⇧ + 4`: Capture selected portion of screen
- `⌘ + ⇧ + 4, then Space`: Capture specific window
- `⌘ + ⇧ + 5`: Open screenshot toolbar
- `⌘ + ⇧ + 6`: Capture Touch Bar (if available)

#### **Mission Control**
- `Control + ↑`: Open Mission Control
- `Control + ↓`: Show application windows
- `Control + ←/→`: Move between desktops

#### **Spotlight and Siri**
- `⌘ + Space`: Open Spotlight
- `⌘ + Option + Space`: Open Spotlight in Finder
- `Hold ⌘ + Space`: Activate Siri

#### **Power & Sleep**
- `Control + Power`: Show restart, sleep, and shut down options
- `⌘ + Control + Power`: Force restart
- `Control + ⌘ + Q`: Lock screen
- `⌘ + Option + Power`: Put Mac to sleep

### **Safari Shortcuts**
- `⌘ + L`: Highlight the URL bar
- `⌘ + R`: Reload page
- `⌘ + [ or ]`: Go back/forward
- `⌘ + ⇧ + \``: Show all tabs
- `⌘ + 1` through `⌘ + 9`: Switch to the tab number 1 through 9

This list covers a wide range of common shortcuts you can use on a Mac.

- `F5`: Start/Continue Debugging
- `F11`: Step Into
- `⇧ + F11`: Step Out
- `F10`: Step Over

- `⇧ + F9`: Toggle Breakpoint Condition
- `⌘ + ⇧ + Y`: Toggle Debug Console

#### **Git**

- `⌘ + ⇧ + U`: View Git Output
- `⌘ + ⇧ + P`: Open Git Command Palette
- `⌘ + B`: Toggle Git Side Bar Visibility
- `⌘ + K, ⌘ + P`: Push
- `⌘ + K, ⌘ + U`: Pull

#### **Extensions**
- `⌘ + ⇧ + X`: Show Extensions
- `⌘ + ⇧ + T`: Reopen Closed Editor
- `⌘ + K, ⌘ + R`: Reload Window
- `⌘ + K, ⌘ + M`: Change Language Mode

### Terminal Shortcuts (Mac)

Here are some commonly used terminal shortcuts for Mac formatted in markdown:

#### **Basic Navigation**
- `Ctrl + A`: Move cursor to the beginning of the line
- `Ctrl + E`: Move cursor to the end of the line
- `Ctrl + U`: Delete from cursor to the beginning of the line
- `Ctrl + K`: Delete from cursor to the end of the line
- `Ctrl + W`: Delete the word before the cursor
- `Option + ←/→`: Move cursor backward/forward one word
- `Ctrl + F`: Move cursor forward one character
- `Ctrl + B`: Move cursor backward one character

#### **Editing**
- `Ctrl + H`: Delete one character backward
- `Ctrl + D`: Delete one character forward
- `Ctrl + T`: Transpose (swap) the character at the cursor with the one before it
- `Esc + T`: Transpose (swap) the current word with the previous word
- `Ctrl + Y`: Paste the last cut text
- `Ctrl + _`: Undo the last operation

#### **Command Control**
- `Ctrl + C`: Kill the current process
- `Ctrl + Z`: Suspend the current process
- `Ctrl + L`: Clear the terminal screen (same as `clear` command)
- `Ctrl + R`: Search the command history
- `↑/↓`: Scroll through previous/next commands in history
- `!!`: Run the last command
- `!n`: Run the nth command from history
- `Ctrl + O`: Execute the command found via `Ctrl + R`

#### **Tab Completion**
- `Tab`: Autocomplete files and folder names
- `Esc + .`: Insert the last argument of the previous command

#### **Window Management**
- `⌘ + T`: Open a new tab
- `⌘ + N`: Open a new terminal window
- `⌘ + W`: Close the current tab
- `⌘ + K`: Clear the screen
- `⌘ + Option + ↑/↓`: Scroll up/down through the terminal output

#### **Panes Management (iTerm2 specific)**
- `⌘ + D`: Split pane vertically
- `⌘ + ⇧ + D`: Split pane horizontally
- `⌘ + ]`: Go to the next pane
- `⌘ + [`: Go to the previous pane
- `⌘ + ⇧ + Enter`: Toggle full screen for the current pane

#### **Miscellaneous**
- `Ctrl + S`: Freeze terminal output
- `Ctrl + Q`: Resume terminal output
- `Ctrl + V`: Insert a literal character (e.g., for typing control characters)
- `Ctrl + G`: Cancel the current command
- `Ctrl + J`: Line feed (similar to pressing `Enter`)
- `Ctrl + M`: Carriage return (similar to pressing `Enter`)

This list includes many essential shortcuts you can use in the terminal on Mac.
