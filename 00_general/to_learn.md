  - ASCII - American Standard Code for Information Interchange
  - Encoding - converting human readable characters to binary sequences that computers can process
  - ASCII Code -- unique 3 digit code
    - A -- 65  Z -- 90
    - a -- 97  z -- 122
    - 0 -- 48  9 -- 57
    - ! -- 33  ? -- 63
  - Extended ASCII -- makes use of the 8th bit as well. We only needed 7 bits to represent what we needed back then
  - Using ASCII one can only store as many as 256 chars. We needed more
  - Unicode -- assigns a unique code called code point
    - A - U+0041 
    - a - U+0061
    - 0 - U+0030
    - ! - U+0021
  - Websites -- They needed to mention what encoding is to be used; It got messed up big time 
  - Emails -- Underlying SMTP Simple Mail Transfer Protocol still required that transferred content be 7 bits
  - DNS -- allows only 7bits ASCII in domain names; Pnycode overcomes this
  - Then came Unicode as a solution
    - If a character can be represented with 1 byte, that is all it will use. If it needs 4bytes, it will use 4
    - Variable length encoding
