- Binart Tree
  - root node
  - parent nodes; child nodes
  - left tree, right tree
  - essential a structured linked list
  - acyclic
  - no separated nodes (nodes not connected to the tree)
  - height(max number of nodes in that longest path from the node till leaf node)
  - depth(number of nodes from a node till root node)
  - O(height) or log(n)
  - advantage over arrays
    - insertion and deletion is also log(n) as opposed to o(n) in arrays
  - alomost log(n) --- because trees might be skewed in which case we do not exactly have log(n).
  - we might even end up with o(n)
- Binary Search Tree
  - Binary Tree with a special recursive property
  - values at the left subtree are smaller than the root value
  - values at the right subtree are larger than the root value
  - min value
    - keep looking left and return the last found value
  - max value 
    - keep looking right and return the last found value
